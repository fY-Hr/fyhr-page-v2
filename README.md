# My Portfolio Page

## Overview

This is a personal portfolio page built with React, Vite, TanStack Router, and Tailwind CSS.

## Prerequisites

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/) (comes with Node.js)

Personally, im using bun, but you can use npm or pnpm.

## Installation

### Clone the Repository

```bash
git clone https://github.com/fY-Hr/fyhr-page-v2.git
cd fyhr-page-v2
```

### Install Packages

To install the required packages, run:

```bash
npm install
```

## Running the Development Server

To start the development server, run:

```bash
npm run dev
```

This will start the development server, and you can access the application at
`http://localhost:3000`.

## Building for Production

To build the application for production, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deploying to GitHub Pages

Push to the `main` branch to trigger deployment to GitHub Pages.

## Built With

- [Vite](https://vite.dev/) - Build tool and development server
- [React](https://react.dev/) - UI library
- [TanStack Router](https://tanstack.com/router) - File-based routing
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [Lucide React](https://lucide.dev/) - Icons
